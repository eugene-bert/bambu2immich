# Security Policy

This project stores your Bambu Lab LAN access code, Immich API key, and optional Telegram bot token. Never paste those into GitHub issues, pull requests, or log screenshots.

## Reporting a vulnerability

Please use [GitHub Security Advisories](https://github.com/eugene-bert/bambu2immich/security/advisories/new).

Do not open a public issue for security reports. You will get a response as soon as possible, and a fix will be released before any public disclosure.
